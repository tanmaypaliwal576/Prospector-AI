================================================================================
STEP-BY-STEP NETLIFY DEPLOYMENT
================================================================================

1. Log into your Netlify Dashboard (https://app.netlify.com/).

2. Click "Add new site" -> Select "Import an existing project".

3. Connect your GitHub/GitLab repository.

4. Configure the site build settings as follows:
   - Base directory:      frontend
   - Build command:       npm run build
   - Publish directory:   frontend/dist

5. Expand "Environment Variables" and add the following variable:

   KEY                  VALUE
   ------------------   --------------------------------------------------------
   VITE_API_BASE_URL    https://prospector-ai-qzg1.onrender.com/api

6. Click "Deploy Site". Netlify will build and publish your site!


================================================================================
IMPORTANT: SET CORS ON RENDER (BACKEND)
================================================================================

Once Netlify finishes deploying and gives you your Netlify domain 
(e.g., https://your-site-name.netlify.app):

1. Go to your Render Dashboard -> Select your backend service ("prospector-ai-qzg1").
2. Go to "Environment" -> Edit Environment Variables.
3. Update `CLIENT_URL` to match your Netlify site URL:
   CLIENT_URL = https://your-site-name.netlify.app
4. Save Changes (Render will automatically redeploy).
